# Porfolio

**My personal portfolio website** — a fast, modern, dependency-free site built with plain HTML, CSS, and JavaScript. Showcasing who I am, what I build, and the projects I've shipped.

> 👤 **Zar Ni Thway** — Junior Fullstack Developer
> 🌍 [zarnithway.vercel.app](https://zarnithway.vercel.app)

## ✨ Features

- 🎨 **Dark / light theme** — persisted toggle, applied before first paint (no flash)
- 📱 **Modern mobile menu** — full-screen glass panel with numbered links, staggered entrance animation, tap-outside/Escape to close, and background scroll lock
- 🖱️ **Custom cursor** — blended cursor + blur follower on desktop
- ✨ **Scroll reveal & counters** — sections and stats animate in as you scroll
- 🧭 **Scroll-spy navigation** — active section highlighted in the nav
- ⚡ **Zero dependencies** — no frameworks, no build step, just open and go

## 🛠️ Tech Stack

| Layer | Tech |
| --- | --- |
| Markup | HTML5 (semantic, accessible) |
| Styling | Modern CSS (custom properties, clamp(), backdrop-filter, CSS counters) |
| Logic | Vanilla JavaScript (IntersectionObserver, no libraries) |

## ▶️ Run Locally

No build tools needed — just serve the folder:

```bash
git clone https://github.com/youuu199/porfolio.git
cd porfolio

# Option 1: any static server
npx serve .

# Option 2: just open it
start index.html
```
